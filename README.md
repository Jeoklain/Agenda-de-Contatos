# Agenda de Contatos

Projeto em C para uma agenda de contatos.

## Estrutura

- `src/main.c`: ponto de entrada do programa.
- `.vscode/`: tarefas de compilação, execução e depuração.

## Como começar

Abra esta pasta no VS Code e use `Ctrl+Shift+B` para compilar. Para depurar, pressione `F5`.

O projeto espera um compilador C (`gcc` ou `clang`) e o depurador `gdb` instalados e disponíveis no PATH.
